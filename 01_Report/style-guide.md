# Report style guide

Taken from the existing draft `MTE4593 Report.docx`, the only report document in the upload. Update this file if another reference report should set the style.

## Layout
- A4, 2.54 cm margins on all sides
- Body text: Aptos (Word's default). Headings: Arial, using Word's Heading 1/2/3 styles so the table of contents updates automatically
- Title page: Title ("SMR", to be replaced with a full title), Subtitle "MTE4593 Assignment 2", authors with student IDs, date of submission
- Numbered headings (1, 1.1, 1.1.1)

## Structure in the draft (to be expanded to cover the brief)
Abstract, Table of Contents, 1 Introduction, 2 Data Sources/Methodology, 3 Discussion (3.1 Overview of SMR: current projects, technical descriptions; 3.2 Lifecycle Analysis; 3.3 National Strategies and Industrial Policies: Australia), 4 Conclusion, 5 References. Appendices (full calculations) are required by the brief and need adding.

## Figures and tables
- Caption format: `Figure N. Description.` followed by a source line `Source: Author (Year).`
- Tables follow the same numbering pattern (`Table N.`)

## Referencing: Harvard, as in the draft's reference list
- Web: `Author/Organisation, Year. Title. [online] Available at: URL.`
- PDF report: `Organisation, Year. Title. [pdf] Place: Publisher. Available at: URL.`
- Journal: `Surname, I., Surname, I. and Surname, I., Year. Title. Journal, Volume(Issue), pp.x–y. Available at: URL.`
- In text: (Author, Year)
- Reference list in alphabetical order (the draft's list isn't yet)
